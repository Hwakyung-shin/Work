# YUN 나의 워크스페이스

혼자 사용하는 한국어 업무 대시보드입니다. 외부 API와 계정 없이 동작하며, 가상 프로젝트 세 개와 샘플 업무로 시작합니다.

## 실행

1. Node.js 18 이상을 설치합니다. 현재 클라우드에는 Node.js 24가 준비되어 있습니다.
2. 터미널에서 이 폴더로 이동하고 `npm start`를 실행합니다. 추가 패키지 설치는 필요 없습니다.
3. 개인 컴퓨터에서는 브라우저로 `http://localhost:3000`을 엽니다. 클라우드에서는 서비스가 제공하는 3000번 포트 미리보기를 이용합니다.
4. 종료할 때는 터미널에서 Ctrl+C를 누릅니다. 다음에는 같은 명령으로 다시 실행합니다.

## 사용

- **업무 추가**에서 업무명, 프로젝트, 종류, 상태, 마감일, 예상 시간, 다음 확인일, 링크를 입력하고 저장합니다.
- 업무명을 누르면 수정 및 삭제할 수 있습니다. 왼쪽 체크박스로 완료·미완료를 전환합니다.
- 별을 눌러 미완료 업무 중 최대 3개를 우선순위로 선택합니다. 직접 해제하거나 완료하기 전까지 유지됩니다.
- 회신 대기는 다음 확인일 순서로 표시됩니다. 프로젝트 이름·분류·현재 단계·설명·다음 행동을 수정하거나 프로젝트를 추가할 수 있습니다. 다음 행동을 비워두면 미완료 업무에서 자동으로 표시하며, 다음 마감과 완료율은 소속 업무에서 집계됩니다. 프로젝트 상세에서 업무 종류별 목록을 확인하고 해당 프로젝트에 업무를 추가할 수 있습니다. 전체 업무는 프로젝트별로 묶이며 프로젝트 필터를 지원합니다. 기존 업무와 예전 백업 파일도 유지됩니다.
- 캘린더에서 월을 이동하거나 날짜를 눌러 해당 날짜 마감 업무를 확인합니다.
- 집중할 업무를 선택하고 25분 또는 50분 타이머를 시작합니다. 일시정지·재개·초기화를 지원합니다. 타이머 실행 상태는 새로고침 또는 앱 종료 시 초기화됩니다.
- **데이터 백업**으로 JSON 파일을 보관합니다. **백업 복원**으로 파일을 선택하면 확인 후 현재 업무 전체를 교체합니다. 먼저 현재 데이터도 백업해주세요.

## 데이터 주의사항

업무는 같은 브라우저·같은 주소의 localStorage에 자동 저장됩니다. 브라우저를 닫아도 유지되지만 시크릿 모드 종료, 사이트 데이터 삭제, 다른 브라우저나 주소에서는 이어지지 않습니다. 중요한 변경 후 백업 파일을 내려받아 안전한 곳에 보관해주세요. 기기 간 동기화와 외부 서비스 연결은 없습니다. 날짜는 사용하는 기기의 현지 날짜 기준입니다.

## 개발

순수 HTML/CSS/JavaScript와 Node.js 기본 HTTP 서버로 구성됩니다. 빌드와 런타임 의존성이 없습니다. 소스 문법 확인은 `node --check app.js` 및 `node --check server.js`로 실행합니다.

브라우저 회귀 검증은 `npm ci --cache /tmp/yun-npm-cache` 후 `npm test`로 실행합니다. 테스트에는 `/usr/bin/chromium`이 필요합니다. 업무 생성·수정·완료·저장, 우선순위 제한, 캘린더, 타이머, 백업·복원, 모바일 가로 넘침을 검증합니다.

## 발주 메모 (v1.3)

오른쪽 아래 **발주 메모** 버튼으로 패널을 열고 접습니다. 넓은 화면에서는 오른쪽에 기본 표시됩니다. **발주 추가**에서 물품명·수량·예정 입고일·현재 단계·다음 확인일·연결 프로젝트·메모를 기록합니다. 카드의 단계 선택으로 발주 준비 → 발주 완료 → 제작 중 → 배송 중 → 입고 완료를 관리합니다. 날짜가 미정인 발주도 등록할 수 있습니다. 확인일이 오늘 또는 과거이면 팔로업 필요, 예정 입고일이 지나면 입고일 지남으로 표시됩니다. 이는 앱을 열었을 때 표시하는 안내이며 외부 알림은 전송하지 않습니다. 입고 완료 건은 기본 숨김이며 체크박스로 다시 볼 수 있습니다. 수정·삭제와 자동 저장을 지원하고, 기존 JSON 백업에 발주도 함께 포함됩니다. 이전 백업을 복원하면 발주가 없는 상태로 교체되므로 현재 백업을 먼저 보관하세요.

## 연도와 발주 보드 (v1.4)

프로젝트 영역의 **관리 연도**에서 프로젝트·전체 업무·발주 메모·발주 보드를 연도별로 봅니다. 오늘의 마감·우선순위·회신 대기와 캘린더는 이 필터와 독립적으로 표시되므로 오래된 미완료 업무도 놓치지 않습니다. 프로젝트와 발주는 편집 창에서 관리 연도(2000~2100)를 지정할 수 있습니다. 여러 해에 걸친 프로젝트도 선택한 연도를 유지하며, 발주 연도는 연결 프로젝트 연도와 별도로 지정할 수 있습니다. 기존 프로젝트는 가장 이른 업무 마감 연도, 기존 발주는 예정 입고 연도(없으면 연결 프로젝트 또는 현재 연도)를 초기값으로 사용하며 직접 수정 가능합니다.

프로젝트 영역의 **발주** 카드, 왼쪽 **발주 보드**, 메모의 **발주 보드 · 이력 보기**로 보드를 엽니다. 메모를 저장하면 즉시 같은 기록이 보드에 나타납니다. 발주 완료·제작 중·배송 중·입고 완료 등 모든 단계가 연도별로 유지됩니다. 입고 완료가 되어도 보드에는 기록이 남으며 삭제 버튼으로 삭제한 경우에만 없어집니다. 각 카드의 **상태 변경 이력**에서 이번 업데이트 이후 저장된 단계 변경 시간과 상태를 확인합니다. 이전 버전에서 발생한 변경 시간은 추정하여 만들지 않습니다. 연도와 상태 변경 이력도 JSON 백업·복원에 포함됩니다.
